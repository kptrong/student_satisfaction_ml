# Student Satisfaction Prediction

Bài tập lớn môn Nhập môn học máy và Khai phá dữ liệu.

## Mục tiêu

Xây dựng mô hình dự đoán mức độ đáp ứng kỳ vọng/hài lòng của sinh viên đối với học phần.

Target gồm 3 lớp:

- Thấp
- Trung lập
- Cao

## Các thuật toán

Các thuật toán Machine Learning sẽ được cài đặt từ đầu:

- K-Nearest Neighbors
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine

Không sử dụng các mô hình Machine Learning có sẵn của scikit-learn trong phần triển khai chính.
